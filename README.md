An offline, plain-canvas cover maker in the style of a GTA 6 box cover. Arrange four layout panels with per-panel pick, zoom and pan, edit the title and subtitle (position, four colours, size slider), apply one of four colour grades, and export a finished cover as PNG at 1080x1080, 1080x1350 or 1920x1080. It runs fully offline with no libraries, no font files and no Rockstar assets.

## Run

Open `app/index.html` in a browser.
